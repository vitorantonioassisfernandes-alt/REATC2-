Como executar:

instalação:
```npm install```

para executar o Vite:

```npm run dev```

Comando entrar no cmd

cd = entrar na pasta
cd .. = sair da pasta
git clone = Clonar repositorio
mkdir = criar pasta
del = deletar arquivo

GIT
git clone (link do repositorio) = pegar seu repositirio
*git init = iniciar o repositorio git
*git config --global user.name logo apos user.email = configurar a conta
*git remote add origin (link do repositorio) = conectar ao seu repositorio remoto
*git add . = transferir todos os arquivos modificados ou algo assim ao repositorio
git commit -m "(deixe alguma mensagem para saber oque foi enviado)" = mensagem de commit
*git push -u origin main = explicar pro vscode aonde o dado vai ser enviado 
*git branch -M main = entrar na main, e sair do master ( sempre que pegar um pc novo)
git pull = receber aquivos que faltam no seu repositorio
git status = para saber oque esta enviado
